# ربات دانلودر اینستاگرام (تلگرام)

## راه‌اندازی
1. از @BotFather در تلگرام یه ربات بسازید و توکن بگیرید.
2. نصب پیش‌نیازها (به پایتون ۳.۱۰ به بالا و ffmpeg نیاز دارید):
   ```
   pip install -r requirements.txt
   ```
3. تنظیم توکن و اجرا:
   ```
   export BOT_TOKEN="توکن شما"
   python bot.py
   ```
   (در ویندوز: `set BOT_TOKEN=توکن شما`)

## نکات
- سقف ارسال فایل برای ربات‌ها 1000مگابایته.
- برای پست‌های خصوصی/محدود می‌تونید کوکی‌های حساب اینستاگرام رو با یه افزونه به‌صورت `cookies.txt` خروجی بگیرید و `export IG_COOKIES=cookies.txt` بزنید. از حساب اصلی‌تون استفاده نکنید، ممکنه محدود بشه.
- اینستاگرام گاهی تغییر می‌کنه؛ اگه دانلود از کار افتاد، `pip install -U yt-dlp` بزنید.
- فقط محتوایی رو دانلود کنید که اجازه‌ش رو دارید و حقوق سازنده‌ها رو رعایت کنید.
